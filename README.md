Mini Golf 3D

A browser-based 3D mini-golf game built with Three.js and Vite.

Tech
- Three.js
- Vite

Run locally
1. Install dependencies:
	npm install
2. Start the dev server:
	npx vite

Controls
- Click and drag: aim
- Release mouse: shoot
- R: reset and play again

Gameplay
- Sink the ball into the hole to complete the current level.
- Use the on-screen prompt to move to the next level.
- Level 3 is the final level.
